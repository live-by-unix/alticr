# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/)
version 2.1.

## Our pledge

We pledge to make participation in this project a harassment-free
experience for everyone, regardless of age, body size, disability,
ethnicity, gender identity/expression, level of experience, nationality,
personal appearance, race, religion, or sexual identity/orientation.

## Our standards

Examples of behavior that contributes to a positive environment:
constructive criticism, respecting differing viewpoints, accepting
responsible correction, focusing on what is best for the community.

Unacceptable behavior includes harassment, trolling, personal or
political attacks, public or private harassment, publishing others'
private information, and other conduct which could reasonably be
considered inappropriate in a professional setting.

## Enforcement

Instances of abusive behavior may be reported to the project maintainer
via the GitHub profile. All complaints will be reviewed and investigated
promptly and fairly.

Project maintainers have the right and responsibility to remove, edit,
or reject comments, commits, code, wiki edits, issues, and other
contributions that are not aligned with this Code of Conduct.
